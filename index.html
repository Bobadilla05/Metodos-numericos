Unidad 7 · Métodos numéricos

Ajuste de curvas

De los datos a los modelos: comprende cómo las matemáticas ayudan a describir y predecir el comportamiento de los sistemas computacionales.

01 · Fundamentos

¿Qué es el ajuste de curvas?

Es un procedimiento matemático que encuentra una función que representa de manera aproximada la relación entre un conjunto de datos. La función permite describir tendencias, estimar valores y hacer predicciones dentro de un contexto determinado.

y = f(x) + ε

x representa la variable independiente, y los valores observados y ε el error o variación que el modelo no explica.

02 · Técnicas

Métodos comunes

Ajuste lineal

Representa una tendencia mediante una recta.

y = a + bx

Ajuste polinomial

Representa relaciones curvas mediante potencias de la variable.

y = a₀ + a₁x + a₂x²

Ajuste exponencial

Modela crecimientos o disminuciones proporcionales a su valor actual.

y = a · eᵇˣ

Ajuste potencial

Modela relaciones donde una variable depende de una potencia de otra.

y = a · xᵇ
03 · Ingeniería en sistemas

Aplicaciones en sistemas computacionales

Rendimiento del software

Relacionar el tamaño de entrada con el tiempo de ejecución para estimar cuánto tardará un programa.

Redes informáticas

Analizar mediciones de tráfico y anticipar periodos de alta demanda o saturación.

Consumo energético

Estudiar cómo cambia el consumo eléctrico al ejecutar programas o utilizar hardware.

Recursos del sistema

Estimar uso de memoria RAM, CPU o almacenamiento ante diferentes cargas de trabajo.

05 · Investigación

Referencias académicas

1. Ferreira et al. (2023)

Forecasting Network Traffic: A Survey and Tutorial with Open-Source Comparative Evaluation. IEEE Access, 11, 6018–6044.

Revisa modelos estadísticos y redes neuronales para predecir tráfico de red y compara calidad de predicción y costo computacional.

Consultar DOI

2. Roy et al. (2022)

CurFi: An automated tool to find the best regression analysis model using curve fitting. Engineering Reports, 4(12), e12522.

Esta investigación presenta una herramienta automatizada para realizar análisis de regresión y encontrar el modelo matemático que mejor se ajusta a un conjunto de datos. Incluye modelos lineales, polinomiales y otros métodos de regresión.

Relación con el ajuste de curvas: aborda directamente el ajuste de curvas mediante regresión y mínimos cuadrados.

Aplicación en ISC: desarrollar aplicaciones web que analicen datos y calculen automáticamente modelos matemáticos.

Consultar investigación

3. Fahs et al. (2023)

Traffic Congestion Prediction Based on Multivariate Modelling and Neural Networks Regressions. Procedia Computer Science, 220, 202-209.

Esta investigación propone diferentes técnicas matemáticas y computacionales para predecir la congestión vehicular, comparando redes neuronales, regresión lineal y regresión polinomial.

Relación con el ajuste de curvas: utiliza directamente modelos de regresión lineal y polinomial para analizar datos y realizar predicciones.

Aplicación en ISC: desarrollar sistemas de análisis de datos para identificar tendencias y predecir comportamientos.

Consultar investigación

Las investigaciones anteriores tratan predicción y modelado de sistemas; no todas implementan exclusivamente el ajuste polinomial clásico. Se incluyen porque sus problemas pueden analizarse mediante modelos de regresión y ajuste de datos.
